Add walk-in customer management to the School module.

DATABASE — New table "school_customers":
- id (serial, PK)
- schoolConfigId (integer, references school_configs)
- firstName (text, required)
- lastName (text, required)
- email (text, required)
- phone (text, required)
- nationality (text, required)
- dateOfBirth (date, required)
- kiteLevel (new pgEnum "school_kite_level": 'beginner', 'intermediate', 'advanced', 'pro')
- weightKg (integer, optional — used for kite size recommendation)
- emergencyContact (text, required — name and phone of emergency contact)
- notes (text, optional)
- createdAt (timestamp, defaultNow)

Create insert schema and type exports.

PAGE — "School Customers" in the sidebar under the "School" group (after School Admin). Visible to admin, manager, and station_lead users — only if their station has an active school_config.

Features:
- Customer table with search across name and email
- Columns: Name | Email | Kite Level (as colored badge) | Nationality | Created Date
- "Add Customer" button → form with two sections:
  Section "Personal Info": First Name*, Last Name*, Email*, Phone*, Nationality* (dropdown), Date of Birth* (date picker)
  Section "Kite Info": Kite Level* (dropdown: Beginner / Intermediate / Advanced / Pro), Weight in kg (optional, number input), Emergency Contact* (text field for name + phone)
  Section "Notes": Notes (optional, textarea)
  (* = required fields)
- The form should be fast to use at a busy kite school reception
- Clickable rows → detail view with editable customer info and a "Billing History" placeholder (text: "No billing history yet")
- Kite Level displayed as colored badge: Beginner=blue, Intermediate=yellow, Advanced=orange, Pro=red
- Managers and station leads can create and view
- Admins can also edit and delete

API ROUTES:
- GET /api/school-customers?schoolConfigId=X
- POST /api/school-customers
- PATCH /api/school-customers/:id
- DELETE /api/school-customers/:id (admin only)
- GET /api/school-customers/:id
